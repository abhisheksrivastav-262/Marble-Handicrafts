# Marble Handicrafts Website

## Build
- Create a polished, responsive one-page brand and collection site at `/`, with the requested hero, about, ten editable collections, benefits, craftsmanship, gallery, custom enquiry callout, enquiry form, FAQ, contact placeholders, and footer.
- Use a distinct editorial artisan aesthetic, semantic design tokens, generated marble product photography, smooth in-page navigation, and accessible mobile menu and image lightbox.
- Add individual page metadata and make all enquiry actions usable without inventing contact details or claiming form submissions are stored.

## Technical details
- Implement the page in the existing TanStack index route; preserve the single-page requirement with section anchors.
- Add the visual system in `src/styles.css`, use existing UI buttons, and use client-side form validation with clear confirmation that does not imply delivery.
- Keep business phone, WhatsApp, address, and email as editable placeholders; no maps until an address exists.
- Run the route test and verify the preview build and the page's key interactions.
